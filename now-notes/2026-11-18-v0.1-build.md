# 2026-11-18: v0.1 build closeout

**Status:** Built, tested, committed and on `main`. Not deployed. Live path verified on 18 November with a key Krish supplied for the run. Benchmark PASS 3/3 against a prompt-matched single call.

**What exists:** TypeScript engine with a seven-stage pipeline (probe, diverge, gate, dialectic, judge, select, hybrid), local semantic embeddings, per-namespace memory, and four interfaces (MCP, HTTP, CLI, library). 21 tests pass. The five reference repos were read at the source level after the first build; three findings changed the design (prompt-matched benchmark control, model rosters, a synthesis step that commits to one decision). Gate calibrated on real embeddings: rewordings rejected 15/15 and non-obvious ideas accepted 15/15 at the balanced setting.

**Next step:** Benchmark done (PASS, about $3.20 for the engine arms). Register the MCP server in Claude Code and point the first consuming engine at it with its own namespace.

**North Star check:** The engine serves the purpose by making non-obvious options legible before they are obvious. It earns its place only if the benchmark shows it beats a single prompt. If it fails, the scoring layer (`score_divergence`) still stands on its own as a novelty meter for the other engines.
